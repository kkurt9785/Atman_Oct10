# Atman / 잇닿

병원·의원·약국이 의료 인력 공고를 게시하고 지원자를 직접 검토·채용한 뒤, 신규 인력과 기존 직원을 함께 관리하는 의료 사업장 인력운영 SaaS입니다.

## 현재 사업모델

- 직업정보 제공: 워커가 공고를 직접 탐색·선택·지원합니다.
- 사업장 직접 채용: 병원·의원·약국이 지원자를 직접 검토하고 채용 여부를 결정합니다.
- 사업장 직접 임금 지급: 잇닿은 임금을 수취·보관·재지급하지 않습니다.
- 정액 SaaS: 매출은 사업장용 공고·근태·휴가·급여 검토·인력풀·관리자 기능 이용료입니다.
- 임금·채용 성공액 연동 수수료는 받지 않습니다.

직업정보제공사업의 기본 원칙에 맞춰 특정 구인자와 구직자의 고용계약 성립을 잇닿이 알선하지 않습니다. 조건 기반 공고 노출과 알림은 정보 탐색을 돕는 기능이며, 지원과 채용 결정은 당사자가 직접 수행합니다.

## 제품 구성

| 영역 | 주요 기능 |
|---|---|
| 워커 | 공고 탐색, 직접 지원, 지원 현황, 사업장 QR·GPS 출퇴근, 휴가 신청 |
| 의료 사업장 | 공고 게시, 지원자 검토, 직원 등록, 근태·휴가 관리, 급여 지급 검토 |
| 공통 데이터 | 공고 → 지원 → 사업장 승인 → 근무기록 → 사업장 직접 지급 |

지원 직군은 간호사·간호조무사와 약사·약국 전산/사무직입니다. 약국 전산/사무직 공고에는 조제·의약품 판매·복약지도 등 약사 면허 업무를 포함할 수 없으며 서버에서도 이를 검증합니다.
약국 공고는 약국 유형·전산 프로그램·일평균 처방량·인수인계 정보를 제공하며, 함께 근무한 약사를 자체 인력풀에서 다시 요청할 수 있습니다.

## 요금 원칙

- Free 파일럿: 직원 3명, 공고 월 3건
- Clinic: 월 59,000원, 직원 10명, 공고 월 3건, 근태·휴가·급여 검토
- Pharmacy: 월 69,000원, 약사·전산직 10명, 공고 월 3건, 반복근무 요청, 근태·휴가·급여 검토
- Basic/Pro/Enterprise: 직원·공고·인력풀·관리자·운영 자동화 범위에 따라 확장

서비스 이용료는 워커 임금과 별도 청구하며 부가세는 별도입니다.

## 워커 런칭 리워드

워커 리워드는 가입자 수가 아니라 실제 근무 가능한 의료인력의 활성화를 목표로 합니다.
임금·병원 결제에 사용하던 레거시 크레딧과 구분하여 `잇닿 리워드`로 운영하며,
병원이 지급하는 임금 및 급여 지급내역에 포함하지 않습니다.

| 단계 | 조건 | 리워드 |
|---|---|---:|
| 프로필 인증 | 신규 가입 후 휴대전화 등록·활동지역·면허 심사 완료 | 커피 쿠폰 5,000원 |
| 첫 근무 완료 | 시프트 출퇴근 완료 및 병원 근태 확정 | 20,000원 |
| 친구 초대 | 초대받은 워커가 첫 근무 완료 | 초대한 워커 10,000원 |
| 초대받은 워커 | 본인의 첫 근무 완료 | 추가 5,000원 |
| 연속 활동 | 추후 2개월·3회 근무·노쇼 없음 기준으로 별도 운영 | 우선 알림 또는 10,000원 |

- 단순 가입 또는 계정 유지 기간만으로 현금성 보상을 지급하지 않습니다.
- 추천은 초대 링크를 통해 가입한 신규 워커가 실제 첫 근무를 완료한 경우에만 인정합니다.
- 동일인·동일 전화번호·자가 추천·중복 계정·취소·노쇼·근태 분쟁은 지급 대상에서 제외하거나 보류합니다.
- 첫 근무 관련 리워드는 근태 확정 후 7일의 검토 기간을 거쳐 지급 대상으로 확정합니다.
- 런칭 캠페인은 예산과 대상 인원을 사전 고지하며 변경·종료 시 앱에서 안내합니다.
- 플랫폼은 특정 병원이나 공고를 추천·배정하지 않으며, 워커가 직접 공고를 탐색·지원합니다.

## 운영 원칙

- 급여 화면의 금액은 병원이 입력한 급여 기준과 근태기록을 바탕으로 한 세전 예상·검토 자료입니다.
- 세금, 4대보험, 법정수당, 일할계산은 병원이 노무·세무 기준에 따라 최종 확인합니다.
- 전체 계좌번호는 직접 등록 직원 테이블에 저장하지 않고 지급 확인용 은행명과 끝 4자리만 관리합니다.
- 면허·자격 상태는 사업장의 지원자 검토를 돕는 정보이며 최종 확인과 채용 책임은 사업장에 있습니다.

## 기술 구성

- `apps/admin-web`: 병원·의원·약국 관리자 PWA
- `apps/worker-web`: 워커 PWA
- `supabase`: PostgreSQL, PostGIS, Auth, Storage, RPC
- Vercel: `admin.itdot.co.kr`, `itdot.co.kr`
