# 결제 알림 자동 수집 — 설정 흐름 재검토 (2026-11-03)

오늘 실기기(iOS 27.2)에서 끝까지 해 본 결과를 바탕으로 쓴 설계 메모. 코드는 아직 손대지 않음.

## 1. 지금 흐름이 복잡한 이유 (실측)
- 가족 설정 탭 맨 아래에 있어 **3화면을 내려야** 카드가 나옴. 카드 안에 1 아이폰 연결(설치·연결) / 2 폰에 자동화 넣기(칩 3개 + 레시피) / 3 연결 확인(수신함) / 수집 주소 직접 설정 / 연결 테스트 / 재시도 버튼 2개가 한 번에 보임. 개발자용 정보와 사용자용 버튼이 섞여 있음.
- 계정 연결의 기본 경로였던 `shortcuts://` 링크가 **환경에 따라 안 열림**(검색창으로 빠짐, 이름 NFC/NFD 불일치). 반면 **클립보드 경로**(앱에서 코드 복사 → 단축어 ▶)는 한 번에 됐고, 이름·URL에 의존하지 않음.
- 미연결 상태의 단축어가 은행 알림마다 팝업을 띄움 → 사용자는 "앱이 고장났다"고 느낌.
- 설치·앱 선택·자동화 켜기는 애플이 사용자 기기에서 직접 하게 강제하는 부분이라 없앨 수 없음(Spenvo·Finny도 동일). 줄일 수 있는 건 **우리 쪽 단계와 화면**뿐.

## 2. 목표 흐름 (iPhone, 새 사용자)
| 단계 | 사용자 동작 | 탭 | 비고 |
|---|---|---|---|
| ① 설치 | 카드의 **단축어 추가** → iCloud 미리보기에서 **추가** | 2 | 트리거·앱 목록 포함 템플릿 |
| ② 켜기 | **단축어 열기** → 카드 ＋로 내 은행 앱 체크 → 〉 자동화 켬 | 3~5 | 애플 강제 구간. 템플릿에 흔한 은행 앱을 미리 넣어 체크만 하게 |
| ③ 연결 | **코드 복사하고 단축어 실행** 한 버튼 → 단축어 앱에서 ▶ → 허용(항상) | 3 | 코드는 클립보드로, 이름 매칭이 되면 자동 실행까지 |
| ④ 확인 | 없음. 앱이 상태를 스스로 바꿔 "연결됨 ✓ · 첫 알림 대기" 표시 | 0 | status RPC 폴링 + 수신함 |

합계 8~10탭, 타이핑 0, 주소 붙여넣기 0. 오늘 실제로는 수정·우회 포함 20탭 넘게 걸렸음.

## 3. UI 재구성
- **위치**: 가계부 탭 상단에 한 줄 상태 `자동 수집 · 연결됨 ✓ · 마지막 수신 12분 전` → 탭하면 시트로 카드. 가족 설정에는 링크만 남김. 미연결이면 홈에 배너 1줄("결제 알림 자동 수집 켜기 · 2분").
- **카드 = 상태 머신 + 버튼 하나**
  - `미설치` → "단축어 추가" (iCloud 링크)
  - `설치됨·미연결` → "코드 복사하고 단축어 실행"
  - `연결됨·알림 없음` → "앱 선택·자동화 켜기 확인" + "단축어 열기"
  - `수집 중` → 최근 수신·이번 달 건수, 수신함은 접힘
  - 상태 판정: 설치는 링크 탭 기록, 연결은 `hg_shortcut_pairing_status`/setup ping, 수집은 수신함 `ios-notification`.
- **고급으로 접기**: 수집 주소 직접 설정·새로 만들기, 연결 테스트 보내기, 문자(SMS) 레시피, 갤럭시 레시피, Mac 중계기, NFC/NFD 재시도, 파일로 받기. 기기 칩 3개는 UA로 자동 선택하고 "다른 기기로 설정" 링크 하나로 대체.
- **삭제**: 파일 공유 설치(`ShortcutFileInstall`의 share/AEA1), `/shortcuts` 안내 페이지, `shortcut-open.html`, "단축어를 찾을 수 없을 때" 전면 버튼(고급으로), 설명문 중 개발 경위.
- **문구**: 단계당 동사 하나. "허용 질문이 나오면 **항상 허용**" 명시. 팝업 대신 앱 안 상태 표시.

## 4. 기능적으로 맞는 방법
- **지금(가족·PWA)**: 템플릿 재공유 1회 — `입력 없음 → 클립보드 가져오기`, 미연결 분기는 **아무것도 안 함**(팝업·Safari 열기 금지), `title/body/via` POST, 헤더 토큰(`x-ingest-token`). 앱은 클립보드 경로를 기본으로, `shortcuts://run-shortcut`은 "되면 좋은" 보조로.
- **출시용(권장 종착지)**: 작은 네이티브 iOS 셸(또는 Capacitor) + **App Intent "하라구리에 알림 보내기"**. 템플릿 단축어 = 알림 트리거 + 이 인텐트 1개. 앱이 로그인 세션을 가지고 있으니 **토큰·코드·페어링·URL 전부 사라짐**(Spenvo 구조). 사용자 흐름은 설치 → 앱 선택 → 자동화 켬, 끝. 비용: Xcode 프로젝트·개발자 계정(가족은 TestFlight)·심사. iCloud 링크 템플릿은 그대로 재사용.
- **갤럭시(아내)**: 알림 리스너 네이티브 앱(설치 + 알림 접근 허용 1번). 같은 ingest·파서.
- **하지 않을 것**: Mac `shortcuts sign` 개인화 파일, 마이데이터·CODEF, 캡처 OCR을 기본 경로로.

## 5. 순서·공수
1. 템플릿 재공유(폰 1회, 10분) + 미연결 분기 무음 + 클립보드 입력 — 빌더 수정 포함 1시간
2. 카드 상태 머신·가계부 탭 이동·고급 접기·문구 — 반나절
3. 상태 자동 갱신(status 폴링·수신함 기반) + 홈 배너 — 2시간
4. (출시 결정 시) 네이티브 셸 + App Intent — 2~3일, 갤럭시 리스너 앱 — 2~3일
