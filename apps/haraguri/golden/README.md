# 정답 데이터 검증 (golden set)

하라구리가 글자를 돈으로 바꾸는 두 곳을 사람이 정한 정답과 비교해 점수를 매깁니다.

| 묶음 | 파일 | 무엇을 보나 |
|---|---|---|
| 알림·문자 | `messages.json` | 수집 서버와 같은 순서(앱 이름 붙이기 → 안내 알림 거르기 → 해석)로 읽은 금액·상호·날짜·카드사·분류·입출금 |
| 이용내역 캡처 | `screens.json` | 캡처를 글자로 읽은 결과에서 가져온 줄, 빠진 줄, 가져오면 안 되는 줄 |

## 명령

```bash
npm run golden          # 항목별 정확도와 실패 사례 전부
npm run golden:update   # 지금 결과를 새 기준으로 저장 (baseline.json)
npm test                # 평소 시험에 포함됨: 기준에서 통과하던 사례가 틀리면 실패
```

- **[회귀!]** 기준에서 통과하던 사례가 지금 틀림. 시험이 실패합니다. 해석기를 고친 쪽을 되돌리거나 다시 고칩니다.
- **[알려진 실패]** 아직 못 맞히는 사례. 해석기를 고친 뒤 `npm run golden:update` 로 기준에 넣습니다.
- **[로컬]** `local/` 폴더의 실제 알림. 보고서에만 나오고 시험을 막지 않습니다.

## 사례 추가

- 정답(`expect`)은 지금 해석기 결과가 아니라 **사람이 보고 맞는 값**으로 적습니다. 확인하고 싶은 칸만 적으면 그 칸만 채점합니다.
- 저장하면 안 되는 알림(광고·포인트·결제 예정·인증번호 등)은 `"expect": null`.
- 실제 가족 알림은 `local/*.json` 에 넣습니다(커밋 안 됨). 형식: `{ "messages": [사례…], "screens": [사례…] }`. 수집함에서 '읽지 못함'으로 남은 알림을 복사해 오면 됩니다.
- 커밋할 사례는 이름·카드번호·계좌를 가립니다(`김*한`, `1002-000-000***`).
