# 하라구리 가계부 검토 — UI/UX · 데이터 흐름 · 수집 로그 분석 (2026-11-03)

읽는 사람: 기한(PM 겸 개발). 근거는 운영 DB 읽기 전용 집계(토큰·키 미출력)와 파서 재현 실행.

## 0. 한 줄 결론

수집 파이프라인은 돌아간다(폰 알림 → 저장 30건, 중복 차단 3건). 문제는 **저장된 뒤**다 — 등록 카드 0장, 자동 수집 지출의 67%가 '기타', 확인 대기 9건, 수신함은 84건의 리워드 알림에 묻혀 있다. 파서 핫픽스 5종 + 규칙 학습 교정 + 카드 자동 등록 제안, 이 세 가지면 가계부가 "읽히는" 상태가 된다.

## 3. 왜 '기타'가 많은가 — 실제 메시지로 파서를 돌린 결과

| 포맷(실제 문구 요약) | 지금 상호 | 지금 분류 | 원인 → 고침 |
|---|---|---|---|
| `[신한카드(2987)승인] … 가맹점명: 롯데쇼핑(주)롯데마트 [신한카드 1544-7000]` | **1544-7000** | 기타 | 마지막 조각 규칙이 전화번호를 집음 → `가맹점명\s*[:：]\s*(.+?)\s*(?:\[|$)` 우선 추출. 신한 4건 전부 |
| `우리WON뱅킹 … [출금] Ａｍａｚｏｎ＿Ａ 148원` | WON뱅킹 입 | 기타 | 전각 문자 → `normalize('NFKC')` |
| `[출금] 토스 김기한 30,000원` | 김기한 | 기타 | 본인 이름 = 내 계좌 간 이동 → `kind: transfer` 자동 |
| `우리WON뱅킹 입출금알림 [입금] 체크할인캐시백 8원` | 할인캐시백 | 이체로 **저장** | `^\[입금\]`만 보고, '입출금알림'의 '출금'에 걸려 incoming 실패 → `\[입금\]` 위치 무관 |
| `MG새마을금고 [출금] 30,000원 … 경일석유(주)덕` | 경일석유 주 덕 | 기타 | 교통 규칙에 `석유|주유소|오일뱅크|SK에너지|GS칼텍스|S-OIL` |
| `가맹점명: 삼성드림소아청소년과` | (1544-7000) | 기타 | 의료 규칙에 `소아과|청소년과|내과|외과|피부과|안과|이비인후과|정형외과|산부인과` |
| `가맹점명: 아이파킹 주식회사` | (1544-7000) | 기타 | 교통 규칙에 `파킹` |
| `가맹점명: 바나프레소 영등포문` | (1544-7000) | 기타 | 식비 규칙에 카페 브랜드 `바나프레소|메가커피|컴포즈|이디야|할리스|폴바셋|텐퍼센트` |
| `토스오더 (광고)[고미베이커 …] 쿠폰 15,000원 이상 결제 시` | 이상 | 씨티카드 **저장** | `(광고)` 표식은 무조건 비거래 |
| `2,000원 결제 페이스페이 (…) · 텐퍼센트커피` | 텐퍼센트커피 양평역점 | 식비 ✓ | 정상 |

이 표의 고침만 적용하면 기타 16건 중 **11건이 바로 분류**되고(신한 4+석유 2+소아과·파킹·바나프레소·Amazon·이체), 오탐 2건이 사라진다.

## 4. 규칙 학습이 오히려 망치고 있다

확정할 때 `learnKeyword(title)`이 **첫 토큰**을 키워드로 삼는다. 지금 규칙 13개 중 9개가 그 결과다:
`1544-7000→기타`, `mg→기타`, `won뱅킹→기타`, `계좌이체→기타`, `아이→기타`, `수원아이→기타`, `간편→기타`, `경일석유→기타`, `사격팡→기타`.
특히 `아이→기타`는 아이파킹·아이파크·아이 통장을 전부 기타로 고정하고, `won뱅킹→기타`는 우리은행 이체 전부를 기타로 만든다. 사용자가 "일단 기타"로 넘긴 선택이 영구 규칙이 된 것.

고침: (1) **기타로 확정할 땐 규칙을 만들지 않는다**, (2) 키워드는 공백 제거한 상호 전체 또는 2글자 이상 토큰 중 은행·카드·전화·조사·'아이' 같은 짧은 일반어 제외, (3) 기존 9개 삭제(사용자 승인 후), `우지커피→식비`·`커피앤메이트→식비`·`해상화재보험→보험`·`아울렛→쇼핑`은 유지.

## 5. 카드 등록 0장 — 가장 싸게 가장 많이 얻는 곳

`matchCard`는 끝 4자리 → 발급사 → 유일 카드 순으로 맞추는데, 맞출 카드가 없다. 로그에서 이미 보이는 결제수단:
신한카드(2987) · NH카드(8\*6\*) · MG체크카드(1\*6\*) · 현대카드(네이버페이 경유) · 올바른POINT체크(올원페이·페이스페이) · 우리은행 계좌(1002-331-728\*\*\*) · 새마을금고 계좌(9003-2867) · 씨티카드(Mac 중계 1건, 오탐일 수 있음).

제안: 확인 대기 카드에 **"신한카드(2987)로 등록할까요?"** 칩 — 발급사+끝4자리가 2번 이상 보이고 매칭 카드가 없을 때. 한 번 등록하면 이후 자동 연결되고 카드별 집계·실적 구간·혜택 제외 카테고리가 살아난다. 계좌는 `payment_method: bank_transfer` 그대로 두되 '우리 생활비 계좌' 이름만 붙이면 보고서가 읽힌다.

## 6. UI/UX — 가계부를 쓰게 만드는 순서

1. **홈 today-line에 '확인 대기 N건'** — 지금은 가계부 안에서만 보인다. 9건이 쌓인 이유.
2. **확인 1탭** — 카테고리 칩은 전체 13개가 아니라 *가능성 높은 3개 + 더보기*, 옆에 카드 등록 칩. 확정 = 1탭.
3. **수신함 기본 보기 = 저장·못 읽음만**, 무시 84건은 "무시 84건 보기"로 접기. 오늘 만든 카드의 '고급'에 이미 반영 가능.
4. **'못 읽음' 재정의** — 금액 패턴이 있는데 실패한 것만. 금액 없는 알림은 무시('금액 없는 알림')로. 그러면 못 읽음 30 → 1.
5. **엄마 폰 연결** — 오늘 만든 2분 플로우의 첫 사용자. iOS 27이면 가계부 탭 한 줄에서 끝, 아니면 '고급 → 아이폰·문자'.
6. **토스 알림 줄이기** — 단축어 앱 선택은 유지하고, 토스 앱 설정에서 혜택·이벤트 알림 끄기(무시 84건 중 60건 이상).
7. **Mac 카카오톡 중계** — 광고 오탐 경로. 폰 단축어가 안정됐으니 끄거나 은행·카드 발신자만 통과.
8. **본인 이체 자동 transfer** — 상대가 가족 이름이거나 내 계좌 끝자리면 지출이 아니라 이동.

## 7. 데이터 흐름(현재)와 빈 곳

```
카드앱 알림 ─ iOS 단축어(알림 트리거, 제목+본문, via=ios-notification, app=빈값) ─▶ ingest(token)
  ├ 빈 본문 → unparsed '빈 전달'
  ├ 연결 테스트 → ignored
  ├ nonTransactionReason(리워드·이벤트·가격인하…) → ignored
  ├ 금액 못 찾음 → unparsed '금액을 찾지 못함'   ← 26건이 사실은 마케팅(=ignored여야)
  ├ 입금 → ignored                                  ← '[입금]' 위치 때문에 1건 누락
  ├ fingerprint 중복 → duplicate
  └ hg_expenses(reviewed=false, source=push, card_id=matchCard→null) → 가계부 확인 대기 → 확정 → learnRule(첫 토큰)
```
확인할 것: iOS 알림 트리거 출력에 **앱 이름 속성**이 있으면 `app`으로 함께 보내기(발급사 보조 식별·앱별 통계·토스 잡음 필터). 폰에서 단축어 편집 화면을 열어 변수 속성 목록을 보면 1분에 확인된다.

## 9. 오늘 작업 자기 검토

- 위험 1 — **iCloud 템플릿은 아직 옛 버전**: 미연결 상태 팝업이 남아 있고 '입력이 없는 경우=클립보드' 설정이 없다. 새 설치자는 `shortcuts://` 이름 호출이 실패하면 수동 ▶ 경로가 안 통한다(코드는 보여 주지만 단축어가 클립보드를 안 읽음). G로 해소.
- 위험 2 — 클립보드 쓰기: iOS Safari는 탭 제스처 안에서만 허용. 프로미스형 `ClipboardItem`으로 제스처를 유지하고, 2.5초 안에 안 끝나면 포기하고 수동 복사 버튼을 연다.
- 위험 2b — 자동 실행(`location.href = shortcuts://`)은 서버 응답 뒤에 일어나므로 iOS가 제스처 밖으로 볼 수 있다. 그래서 같은 자리에 **단축어 열기** 링크를 항상 남긴다(실패해도 한 번 더 탭). 실기기에서 첫 탭만으로 열리는지 1회 확인 필요. 헤드리스 크롬은 이 시도 뒤 실제 클릭을 버리는 특성이 있어 E2E는 DOM 이벤트로 탭한다.
- 위험 3 — 상태 플래그(`installed`·`enabled`)는 기기 localStorage. 다른 기기에서 열면 1단계부터 다시 보이지만, 연결·수집 증거는 서버(설정 핑·토큰)라 '연결됨/수집 중'은 어디서나 같다.
- 유지한 것: `?tab=settings` 딥링크, `/pair` 콜백 페이지, 문자·갤럭시 레시피(고급 안), 수집 주소 새로 만들기·끄기(확인창 유지).
- 스크립트: `review-ui.mjs`(탭 4+설정 버튼), `smoke.mjs`(설정 버튼), `verify-shortcut-onboarding.mjs`(새 카드 플로우로 재작성).
