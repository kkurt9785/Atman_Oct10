## 2차 (같은 날 오후) — 대화 종료·썸네일·다중 선택

- 사용자 결정: **종료 = 사진 삭제 + 글 보존, 자동 아님(제안형)**.
- 추가: `hg_rooms` + 종료 방 쓰기 차단 트리거, 가족 단위 첨부 삭제 정책, 상세 화면 종료 제안 배너(완료·구매 완료/보류 시), 종료 방 읽기 전용 + 다시 열기, '우리집 일' 진행 중/종료됨 탭, 사진 썸네일(320px) 동시 업로드·목록은 썸네일만 로드, 한 번에 10개 선택.
- QA 1 스모크에 추가: 구매 완료 → 배너 → 종료 → 입력창 사라짐·글 유지 → 종료됨 탭에서 열기 → 다시 열기. PASS(페이지 오류 0).
- QA 2 실제 DB에 추가: 외부인 종료 불가, 멤버 종료 → 메시지·파일 insert 거부(트리거), 기본 채팅은 영향 없음, 멤버가 다른 멤버 파일·행 삭제(정리 권한), 다시 열기 → 입력 가능. PASS. vitest 28건.
- 스모크 중 수정 2건은 모두 스크립트 쪽(공유 후 기본 채팅 뷰에 머무는 흐름, 카드 접근성 이름에서 배지가 제목보다 앞). 앱 수정 없음.
