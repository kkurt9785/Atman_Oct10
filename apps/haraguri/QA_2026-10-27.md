## 8차 — 가계부 첫 화면 재배치 (1차 묶음) · 채팅 알림 유도

- 점검 결론: 기능은 다 있었지만 배치가 "입력·설정 중심". 모바일에서 숫자가 1,100px 아래, 최근 내역이 3,500px 아래였음.
- 바꾼 것: 상단 **‹ 월 › 요약 바**(이번 달·오늘·지난달 같은 날까지 대비) → 필터는 **"필터 (n)" 버튼으로 접기** → 확인 대기 띠 → **날짜별 그룹 내역**(일 합계 헤더, 대기 항목은 행에서 바로 [확인]) → 카드별 실적·날짜별 차트는 **접힌 섹션**. 월 이동은 화살표 1탭(피커는 월 글자 탭). 데이터 탭에선 모바일 설명 문장 숨김.
- 대화 탭: 푸시를 안 켠 기기에 "알림 켜기" 띠(iPhone 미설치 브라우저엔 홈 화면 추가 안내). 푸시 함수는 비밀키 설정 확인(인증 없는 호출에 403).
- QA 1 스모크: 날짜 그룹 헤더·필터 토글 개수 표시·행 [확인] 버튼·대기 띠·월 화살표 검증 추가. PASS. QA 2: 접힌 카드 섹션·필터를 여는 단계만 스크립트에 추가, 전 항목 PASS.
- 남은 묶음: 2차(입력 폼 간소화·카드 요약화·비교 카드), 3차(데스크톱 2단·리포트 색).

## 9차 — 가계부 2차·3차 묶음

- **입력 폼**: 기본 노출 금액(자동 포커스·숫자 키패드)·사용처·분류 칩 13개(1탭) → "자세히 ▾"에 날짜·결제수단·카드·실적·우리집 일 연결. 토글 줄에 "오늘 · 우리 생활비 카드"처럼 적용 중인 기본값 표시. **마지막 결제수단·카드 기억**(`haraguri-last-pay-<uid>`), 카드 결제인데 카드가 안 정해지면 자동으로 펼침. 숨긴 필드도 폼 값으로 제출되도록 `hidden` 속성 사용, 카드 select의 required는 제거(JS 검증 유지).
- **카드 실적 카드**: 이름·인정 실적·진행바·"다음 구간까지 N원"만 보이고, 구간·혜택 기준·예산·한도·메모는 "자세히" 접기.
- **데스크톱 2단**(≥1101px): 왼쪽 대기 띠+내역, 오른쪽 카드 실적·날짜별 차트(넓은 화면은 기본 펼침).
- **리포트**: 월 이동 ‹ › 화살표, 분류 증감은 빨강 대신 주황(증가)/초록(감소)/회색(신규·동일).
- QA 1 스모크: 분류 hidden input 검증, "자세히" 열기 헬퍼, **두 번째 입력에서 결제수단이 '현금'으로 기억되는지** 확인 추가. 중첩 details 때문에 summary 선택자를 직계 자식(`:scope > summary`)으로 좁힘(스크립트 수정, 앱 문제 아님). PASS. QA 2 전 항목 PASS.

## 10차 — 안 읽음 추적 · 아이콘 배지 · 안 읽은 메시지 리마인드 (카카오·라인처럼)

- 사용자 확인: 테스트 푸시 아이폰 수신 OK → A(아이콘 배지)+B(리마인드) 승인.
- DB: `hg_room_reads`(+`hg_mark_read`), `hg_unread_summary`, `hg_unread_reminders`, `hg_members.joined_at`, 푸시 기본 설정에 `unread`, pg_cron `haraguri-unread-reminder`(매시 20분). 푸시 함수: 메시지·파일 푸시를 **받는 사람마다** 따로 보내며 `badgeCount`(그 사람의 전체 안 읽음 수) 동봉, `unread` 종류 추가(2h 경과·새 글·6h 간격 규칙). 서비스 워커: `badgeCount`로 `setAppBadge/clearAppBadge`.
- 화면: 대화 탭(하단·사이드) 숫자 배지, 대화 종류 탭 숫자, 우리집 일 카드 숫자, 방이 보이는 동안 자동 읽음, 포그라운드 복귀 시 갱신, 앱이 열려 있을 때 아이콘 배지 동기화. 알림 설정에 리마인드 토글. 알림 탭 안내 문구 현실화.
- QA 1 스모크 PASS(미리보기엔 안 읽음 없음 → 회귀 확인). QA 2 추가: 멤버 댓글 → 소유자 안 읽음 1(작성자 이름 포함) → 타인 수치 조회 불가(빈 배열) → 읽음 처리 → 0 → 외부인 읽음 처리 거부. 전 항목 PASS. 운영에서 `kind:unread` 호출 200(리마인드 대상 없음 → 0건, 정상).
- 실기기 확인 필요: 아이폰 아이콘 배지는 설치본에서 푸시가 올 때 표시되는지(iOS 16.4+), 안드로이드 Chrome 배지.

## 11차 — 채팅 1차(메신저 문법): 위챗·왓츠앱·텔레그램·라인 대조 후 구조 수정

- 모바일 **전면 채팅**: 대화 탭·기본 채팅일 때 `main.chat-full` — 제목·설명 숨김, 모임 선택은 한 줄로 압축, 메시지 영역이 남는 높이 전부(100dvh 기준, 기존 340px 고정 → 약 2배). 데스크톱은 `min(62vh,600px)`.
- **날짜 구분선**(오늘·어제·M월 D일 (요일)) + **같은 사람 5분 내 연속 메시지 묶음**(이름 1번) + **시간은 말풍선 옆** "오후 4:36" + 수정됨 표시.
- 수정·삭제·복사는 **길게 누르기(터치)/우클릭(마우스) 메뉴**로. 평소엔 숨김. 터치 기기에선 말풍선 텍스트 선택·콜아웃 비활성(복사는 메뉴로).
- **입력창 한 줄 자동확장** + 왼쪽 ＋(첨부, 숨긴 파일 input) + 오른쪽 ↑ 전송. **Enter 전송**(마우스 환경, 한글 조합 중 제외)·Shift+Enter 줄바꿈. 안내 문구는 ＋ 버튼 툴팁으로. 방의 "대화 종료"는 헤더로.
- **낙관적 전송**: 보내자마자 반투명 말풍선 "전송 중…", 실패 시 "전송 실패 · 다시 보내기/지우기". 실제 행이 오면 교체.
- **새 메시지 N개 ↓** 버튼(위로 올려둔 상태에서 도착 시), 방 열 때 **"여기까지 읽었어요"** 구분선에서 시작(안 읽음 수 기준).
- QA 스크립트 조정 3건(앱 문제 아님): ① 수정·삭제는 우클릭 메뉴 경유 ② 낙관적 말풍선이 먼저 보이므로 DB 확인 전엔 `.chat-bubble:not(.pending)` 대기 ③ 전면 모드에서 연결 상태 글자·모임 선택을 숨겼다가 **다시 노출**(사용자에게도 필요) — CSS 수정. 스모크에 날짜 칩·Enter 전송·메뉴 경유 수정/삭제 추가. QA 1·2 전 항목 PASS.
- 남은 묶음: 2차(읽음 표시·답장·리액션·사진 뷰어/그리드), 3차(공지 고정·검색·음성).

## 12차 — 채팅 2·3차: 읽음 표시·답장·리액션·사진 뷰어/그리드·공지 고정·검색·음성

- DB: `hg_comments.reply_to`(같은 모임만, 트리거), `hg_reactions`(6종 고정·멤버만·본인 삭제), `hg_room_reads` 가족 조회 허용(읽음 표시), `hg_pins` + `hg_pin_message`(방당 1개, 교체), 버킷에 오디오 MIME, 실시간 발행 3테이블 추가.
- 화면: 길게 누르기 메뉴에 **리액션 6종·답장·복사·고정·수정·삭제**. 답장은 입력창 위 미리보기 + 말풍선 위 인용(탭하면 원문으로). 리액션 칩(내 것 강조, 탭으로 토글). 내 메시지 옆 **"읽음"/"읽음 N"**(라인식, 상대 읽음 기록 기준). 연속 사진은 **그리드**, 탭하면 **전체화면 뷰어**(좌우 스와이프·저장). 방 상단 **📌 고정 띠**(탭→원문). 헤더 ⌕ **검색**(결과 탭→해당 방·메시지 하이라이트). 입력 비었을 때 🎙 **음성 메시지**(최대 60초, 업로드 후 인라인 재생).
- **사용자 버그 신고 "대화 알림 숫자가 확인해도 안 지워짐" → 원인**: `hg_room_reads`를 실시간 발행에 넣으면서 기본키 없는 테이블의 UPDATE가 "replica identity" 오류로 거부 → 읽음 처리가 조용히 실패. `replica identity full`(hg_room_reads·hg_pins) 적용 후 운영에서 임시 계정으로 읽음·고정·해제 모두 OK. 앱도 실패를 콘솔에 남기도록 수정. 추가로 **방을 읽으면 그 방의 OS 알림을 닫고**, 안 읽음 0이면 채팅 알림 전부 닫음(카카오 방식).
- QA 1 스모크 추가: 답장 인용·👍 리액션 칩·고정 띠/해제·검색 결과. 선택자 함정 1건(답장 인용문이 원문과 같은 글자라 `.last()`가 답장을 집음 → `:not(:has(.quote))`). QA 2 추가: 같은 모임 답장 강제, 리액션 멤버·이모지 제한, 고정/해제, 읽음 기록 가족 조회, **두 번째 브라우저가 기본 채팅을 보고 있으면 자동 읽음 처리되어 안 읽음 0**(UI 경로). 전 항목 PASS.
- 실기기 확인 필요: 음성 녹음(iOS Safari MediaRecorder mp4), 사진 뷰어 스와이프, 알림 자동 닫힘.
