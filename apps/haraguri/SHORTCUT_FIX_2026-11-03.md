# 단축어 연결 반복 안내 수정 · 2026-11-03

## 확인한 문제

- 기존 개인 단축어 `하라구리 앱 알림 2`의 실제 알림 수집은 계속되고 있었습니다. 새 공유 단축어는 계정 연결되지 않아 반복 안내를 띄웠습니다.
- Mac 동기화 목록에서 공유 단축어의 실제 이름은 NFD였습니다. NFC 이름 호출은 아이폰에서 `단축어를 찾을 수 없습니다`로 실패했습니다. 이름 찾기 단계의 실패는 기대한 x-error 콜백을 보내지 않아 자동 재시도로 복구되지 않았습니다.
- 앱 수동 연결 테스트(`via=test`)는 실제 단축어 계정 연결의 증거가 아닙니다. 사용자 연결 기록에는 코드 소비/연결 시험 기록이 없었습니다.

## 수정·배포

- 현재 iCloud 배포본에 `name_normalization:NFD`를 명시해 실제 설치 이름을 먼저 호출합니다. 향후 NFC 공유본은 매니페스트 값만 변경할 수 있습니다.
- 이름 찾기 실패 콜백이 오지 않을 때 `단축어를 찾을 수 없을 때`로 같은 미사용 코드를 한 번만 다른 이름 형식으로 실행합니다. 서버에서 pending 상태를 확인하며, claimed/expired 코드는 실행하지 않습니다.
- /pair도 동일한 매니페스트를 사용합니다. 콜백에 실제 실행한 이름 형식을 담아 성공한 호출 방식을 기억합니다.
- 연결 완료를 최근 수신함 30건에서만 찾던 버그를 수정했습니다. 마지막 아이폰 연결 시험 기록을 별도로 조회하며 수집 주소가 새로 발급되면 이전 증거는 제외합니다.
- 실제 앱 알림 전달 기록이 있는 아이폰은 문자 설정으로 되돌아가지 않게 했으며 사용자 수동 선택은 존중합니다.
- 가족 설정 상단에 `알림 수집 계정 연결` 바로가기를 추가했습니다.
- Vercel 운영 배포 READY: `dpl_Hztpn8YpsoZTurp9Evv8at1G8MLq` / https://haraguri.vercel.app
