# 하라구리 단축어 후속 작업 · 2026-11-02

## 적용 범위

사용자 다운로드 작업지시서 T1~T5 기준. 지시서의 자동 배포 금지는 후속 사용자 지시 “일단 문제 없음 배포까지”로 변경됐습니다.

- T1: `%20` 이름 인코딩 유지, NFC 실행 실패 시 본인 코드 상태를 조회하고 같은 미사용 코드를 NFD로 한 번만 재시도합니다. 만료·소비된 코드·두 번째 실패는 재시도하지 않습니다. URL에서 코드를 즉시 제거하고 연결 페이지의 referrer를 차단합니다. 검사기에 NFC/NFD 표시와 경고를 추가했습니다.
- T2: 설치 버튼을 검증한 iCloud 링크로 바꿨습니다. 사용자가 설치 후 연결을 시작하면 설치 단계를 접고, 연결 테스트가 확인되면 연결됨 한 줄로 축소합니다. 은행·결제 앱 이름 그림과 앱 선택 안내를 추가했습니다. 실제 은행 앱 로고 파일은 사용하지 않았습니다.
- T3: `/pair` 페이지에서 로그인·가족 확인 후 코드 발급과 실행을 지원합니다. 미로그인은 이메일 로그인 후 돌아옵니다. 여러 가족이고 이전 선택이 없으면 선택을 받습니다. 생성기의 미연결 분기는 `/pair`를 열도록 바꿨습니다. 완성된 원본의 연결 테스트 POST를 건너뛰고 실제 알림 본문을 추출하도록 보완했습니다. Mac 서명 경로는 제거했습니다.
- T4: 연결 서버는 v2 `token`, `ingest_url`과 기존 `collect_url`을 함께 반환합니다. 새 템플릿은 토큰만 저장하고 `x-ingest-token` 헤더로 제목·본문을 보냅니다. 현재 설치된 v1 단축어는 기존 방식으로 계속 작동합니다.
- T5: 미추적 테스트 파일을 제거하고 README를 갱신했습니다. 휴대폰 복제본 삭제 및 기존 개인 단축어 자동화 해제는 아래 실기기 전환 조건이 충족되지 않아 보류했습니다.

## 검증

- Vitest 131 통과, 1 기존 건너뜀. Python 단축어 테스트 17 통과.
- TypeScript 및 Next 프로덕션 빌드 통과.
- 운영 DB에 연결 상태 조회 함수 적용, 마이그레이션 이력 반영.
- `shortcut-pair` 서버 함수 배포. 임시 계정으로 본인/외부 가족 상태 격리, 코드 만료·1회 사용·동시 소비, 기존 수집 주소 유지, 헤더 인증 테스트 ping, 결제 중복 무시 검증 통과.
- 전체 서버 검증의 마지막 브라우저 단계는 기본 로컬 포트가 꺼져 종료했습니다. 그 이전 서버 검증은 통과했고 임시 자료는 정리했습니다. 별도 모바일 브라우저 연동 검증은 통과했습니다: iCloud 링크, NFC/NFD 한 번 재시도, 소비된 코드 차단, 연결과 실제 결제 분리, 수집 주소 재발급 후 증거 초기화를 확인했고 임시 자료를 정리했습니다.

## 실기기에서 남은 일

현재 미러링은 “iPhone을 찾을 수 없음” 상태입니다. 웹·서버 배포와 휴대폰 단축어 전환은 별개입니다.

1. 현재 공유본은 APPROVED, 트리거 1개, 개인 토큰 없음이지만 이름 NFD·앱 선택 10개가 남아 있고 제목 전송·자동 연결·헤더 인증을 넣기 전 버전입니다.
2. `shortcut-drafts/haraguri-notifications-v2.plist`는 무토큰 원본에서 생성한 검토용 초안이며 설치·iCloud 게시된 파일이 아닙니다. iPhone에서 최종 편집·설치하고 이름 NFC·앱 선택 초기화를 확인한 뒤 새 iCloud 링크로 공유해야 합니다.
3. 새 링크 검사와 NFD 이름 연결, 실제 은행 알림 제목·본문 저장을 확인한 뒤 manifest 링크를 전환합니다. 현재 링크로 자동 연결·헤더 전송이 된다고 안내하면 안 됩니다.
4. 새 연결·실제 수집이 확인된 뒤에만 개인용 `하라구리 앱 알림 2`의 자동화를 끕니다. 이 개인 단축어는 공유·삭제하지 않습니다. 복제본 `하라구리 알림 수집범ㅇ`은 그때 정리합니다.
5. 결제 2건 이상 하루 운영 확인은 이후 실제 알림으로 진행해야 합니다. 테스트 ping·수동 복구를 자동 수집 증거로 계산하지 않습니다.

이번 변경은 단축어 연결 작업이며 개인 가계부 과거 원장의 일괄 보정 SQL은 실행하지 않았습니다. 월급일 집계·자산 관리·추가 수집 API 도입 같은 큰 결정은 `REVIEW_2026-11-02.md`를 참고합니다.
