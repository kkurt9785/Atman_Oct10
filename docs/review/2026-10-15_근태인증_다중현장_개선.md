# 근태 인증·좌표·다중 현장 개선

## 반영

- 인증 설정의 기본 선택을 간편 인증 / 강화 인증(위치와 QR 모두 필수) / 관리자 처리로 정리했다. 기존 GPS 우선·QR 전용·등록 네트워크 전용 설정은 고급 항목으로 보존한다.
- 출퇴근 실행 전 서버에서 본인에게 배정된 근무의 최신 인증 규칙을 조회한다. 관리자 처리 모드에서는 자동 출퇴근 성공으로 표시하거나 승인 요청을 보냈다고 주장하지 않고 관리자 확인으로 안내한다.
- 강화 인증의 GPS 실패·네트워크 전용·관리자 처리·QR 보완 비허용에는 잘못된 QR 대체 버튼을 표시하지 않는다. 성공 후에는 앞선 위치 실패 경고를 숨긴다. 간편 방식의 GPS API 대기 설정은 4초, 강화 방식은 12초다.
- Wi-Fi는 SSID가 아니라 공인 IP를 비교한다는 점과 IP 변경·VPN·IPv4/IPv6 차이를 설정 화면에 명시했다. 이번 변경으로 프록시 헤더의 위조 방지 검증까지 완료한 것은 아니다.
- 현장 생성 시 검색·GPS 권한 없이도 지도를 바로 열어 클릭/핀 이동으로 지정할 수 있다. 초기 지도 중심은 선택값으로 저장하지 않는다. 주소 없이 좌표 저장·수정이 가능하며 기본 안내명은 ‘위치 기반 근무지’다.
- 사장님 설정 → 사업장·현장 관리(`/sites`)에서 여러 단기 현장을 추가한다. 현장은 기존 facility 단위로 분리하며 각자의 직원·계약 일정·근태·지급·좌표·인증 설정을 사용한다. 합산 보고서나 한 계약의 여러 현장 이동 배정은 이번 범위가 아니다.
- DB의 단일 소유 제약은 의료 사업장에 유지하고 단기 현장만 복수 소유를 허용한다. 생성 요청 UUID와 소유자별 잠금으로 같은 요청 재전송의 중복 현장 생성을 방지한다. 시연 계정은 실제 현장을 추가하지 못한다.
- 현장 전환 시 확인 후 전체 화면을 다시 열어 이전 현장의 입력값과 캐시가 새 현장에 남지 않게 한다.
- 관리자 QR에 현장 식별자를 함께 넣어 워커가 해당 연결을 먼저 선택하도록 한다. 로그인 복귀 시에도 식별자를 유지하고, QR 현장과 선택한 근무의 서버 기준 현장이 다르면 기록을 진행하지 않는다. 최종 QR 유효성은 기존 서버가 검사한다.
