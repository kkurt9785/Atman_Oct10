# 워커 홈·근무표 개편

- 홈의 D/E/N 혼합 표와 긴 공고 목록을 제거하고 출퇴근 진입 → 다음 근무 카드 → 지원 대기 요약 → 근무 찾기로 분리했다.
- 내 근무의 기본 화면은 날짜·실제 시간·사업장·상태를 읽을 수 있는 카드다. 월 선택과 달력 보기를 제공하고 날짜를 누르면 해당 날짜의 일정을 표시한다.
- 공고 지원 일정 카드는 해당 지원의 상세 영역을 열고 이동한다. 기존 출퇴근·사업장 채팅·지원 취소·대타 요청 기능은 상세에서 유지한다.
- 기존 직원의 계약 기간·근무 요일을 일정에 포함한다. 확정 배정으로 오해하지 않도록 ‘계약 기준 예정’이라고 표시한다. 휴가·변경·실제 근태까지 반영한 확정 근무표는 아니며 안내 문구를 제공한다. 해당 직원의 사업장으로 연결한다.
- 근무 찾기의 두 지역 통합·날짜·거리·시급 탐색은 유지한다. 의료/긱 셸 구분과 긱 전용 화면은 변경하지 않았다.
- 근무 중인 단기 근무 우선, 야간 종료의 익일 처리, 조회 실패와 빈 일정 구분, 다시 불러오기, 지원 상태 변경 후 일정 재조회.

## 검증

- Vitest 187개 통과(신규 일정 계산 테스트 6개 포함).
- 네트워크 허용 프로덕션 빌드 및 타입 검사.
- Chrome 360/390px 실제 일정 컴포넌트 + 모의 데이터: 날짜 카드, 달력 선택, 상세 링크, 조회 실패/재시도, 가로 넘침 없음.
- 운영 배포 후 공개 시연 계정으로 홈·달력·상세 연결·근무 찾기 확인. 실제 지원/출퇴근/결제는 실행하지 않는다.

이 작업은 워커 웹 UI 변경이다. Android 실기기·스토어 제출 검증을 대체하지 않는다.
