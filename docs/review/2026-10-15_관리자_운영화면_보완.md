# 관리자 운영 화면 보완

## 수정

- 7일 일정에서 단체 근무와 개별 근무를 동시에 표시. 같은 사람·같은 시작/종료 시간만 중복 제거하고 날짜 버튼에 별도 인원 표시.
- 운영 홈과 오늘 근태의 출퇴근 시각에 한국 시간대 적용. 확인 요청 기한도 기기 시간대와 무관하게 한국 시간으로 해석하고 지난 기한·잘못된 날짜 차단.
- 단체 발송에 동기 실행 잠금, 예외 처리, finally 잠금 해제 추가. 발송 중 팝업 닫기와 내용 변경 차단.
- 발송 전 현장과 대상자 이름 확인. 0명·일부 전달·결과 불명확 상태를 구분하고 푸시 수신을 보장하는 문구 제거.
- 팝업 높이 제한/스크롤, 본문 입력 글자 크기, Escape 닫기 및 Tab 초점 순환 보완.
- 지급 완료 내역을 10건씩 페이지 조회. 근무자 이름 검색과 홈에서 해당 근무자 지급 화면 바로가기 추가.
- 근태 처리 버튼에서 선택 근무자만 조회하고 전체 조회로 돌아가는 링크 제공. 오늘 근태 경로이므로 과거 날짜 조회를 새로 구현한 것은 아님.
- 관리 메뉴에 사업장·행사장 관리 추가. 지급 메뉴는 지급 화면과 동일한 역할/급여 조회 권한일 때 표시.

## 검증

- 관리자 프로덕션 빌드 성공.
- 회귀 테스트 204개 통과(이번 순수 규칙 테스트 9개 포함).
- 실제 운영 홈 컴포넌트 + 모의 전송으로 360/390px Chrome 검증: 혼합 일정, 미국 시간대에서도 한국 시간 표시, 동시 클릭 1회 전송, 네트워크 예외 후 잠금 해제, null/0/부분 성공 응답, 과거 기한 차단, 한국 시간 기한 전달.
- 운영 DB 및 실제 근무자 메시지/알림에 대한 쓰기는 하지 않음. 실제 푸시 수신 검증은 별도.

## 범위 및 남은 점

- 최초 검증 시점에는 로컬 수정까지 완료. 이후 사용자 요청으로 관리자 앱 커밋·푸시 및 운영 배포 진행. DB 스키마/급여 계산 변경 없음.
- 발송 잠금은 동일 화면 내 중복 실행 방어. 응답 유실 후 수동 재전송/여러 기기 간 exactly-once를 보장하는 서버 idempotency는 별도 과제. 결과 불명확 시 대화방 확인 후 재전송 안내.
- 지급 기간 필터와 홈 전체 정보 배치 재설계는 이번 범위에서 제외. 지급 데이터 읽기 모델의 기존 1,000건 안전 제한 유지(대규모 내역은 서버 페이지 조회 추가 필요).
- 모든 관리자 페이지 또는 Play 출시 전체 검증 완료를 의미하지 않음.
