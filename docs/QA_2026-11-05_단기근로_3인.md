첫 영업 대상을 단기·행사 현장(팝업·행사·단기 인력업체)으로 정한 뒤, "당장 쓸 수 있나"를 세 역할로 나눠 봤다. 운영 DB 쓰기 0건(저장·수락·초대·지급 버튼 안 누름, 시연 초기화 안 부름). 작은 것은 바로 고치고 큰 것은 아래에 남겼다.

## 고친 것

**사장님(admin-web)**
- 근무 만들기: 기간·반복 근무면 "기간 중 N일 근무 · 1인 ○원 · 8명 ○원 (주휴수당 별도)" 표시. 메모 안내 '관리자만 봄' → '사장님만 봐요'.
- `/staff`: '긱워커' → '근무자'(제목·등록·목록), 빈 화면에 다음 할 일 안내, 수락 대기에 실제 만료일("11/12까지 열려요"), 재발급·초대·빼기·대화 버튼 40px.
- 초대 복사: 공유 시트가 없을 때 링크만이 아니라 "[잇닿] 근무 초대가 왔어요… + 링크"를 복사, QR 창 이름 '근무 초대 QR'.
- `/timesheet`: 긱 모드 '관리자 직접 처리' → '사장님이 직접 처리', 미출근 안내 해요체. `/gig-pay`·`/gig-work/[id]`의 '긱워커'·'워커' 정리.
- `/gig-work` 404 → 홈으로 이동(새 파일).

**근무자(worker-web)**
- 초대 링크: 만료·사용된 초대에 '내 근무 열기' 버튼(이미 수락한 링크를 다시 누르는 경우), 오류 제목 '초대를 열지 못했어요', 긱 초대 문구 '관리자' → '사장님', 카카오톡 안에서 열면 "다른 브라우저로 다시 열려요, 노란 버튼을 한 번 더" 안내.
- 워크룸 입력 안내·개인정보 줄 '사장님', 알림 빈 화면 '사장님 공지, 출퇴근 기록, 지급 소식', 다음 근무 설명 한 줄로.
- 지급 화면: '이번 달 인정' → '이번 달 근무', 홈 링크 `<Link>`, 계좌 '변경' 44px.

**시연·공개 페이지**
- `/intro`·설치 버튼 '워커' → '근무자'. `/gig/demo` 배지 'DEMO' → '시연', 설명 정리, **'사장님 화면도 시연해 보기 →'**(`admin.itdot.co.kr/login?demo=gigworker`) 추가.
- `DEMO_GUIDE.md` 0장 '단기·행사 시연' 신설: 사장님 `login?demo=gigworker`, 근무자 `/gig/demo`, 사장님께 남길 QR `/intro?role=admin&kind=gigworker`.

검증: admin-web·worker-web `tsc --noEmit` 통과, 고친 화면 390px 재촬영(초대 복사·만료일 표시는 시연 근무자가 `DEMO-` 번호라 화면 확인 못 함).

## 큰 것 (안 고침, 결정 필요)

### P0
- **무료 베타 한도 3명이라 8명 팝업은 4번째 초대에서 막힌다.** 초대 대기·미래 계약도 센다(`lib/billing-gates.ts:51-54`, 값은 DB `service_plans.included_attendance_slots`). 단기 요금표는 "아직 판매하지 않아요"라 늘릴 방법도 없다. → 긱 베타 한도 상향(10~20명, DB 변경) 또는 단기 요금 판매 시작, 최소한 한도 오류에 문의 버튼.

### P1
- 8명 초대가 1명씩 8번(`GigParticipantsPanel.tsx:51-61`) → 이름 여러 줄 일괄 등록 또는 인원 한도 공용 링크(액션·RPC).
- 초대 → 가입 단계가 많다: 카톡 안 버튼 → 외부 브라우저에서 한 번 더 → 카카오 로그인 → 약관 → 인적사항 → 계좌(긱은 건너뛰기 없음, `onboarding/page.tsx:211`) → `/gig/join`에서 '초대 수락' 또 누름. → 초대에서 온 가입은 끝나면 자동 수락, 계좌 '나중에' 허용 여부 결정.
- 출근 가능 시간을 누르기 전엔 모름(`gig/page.tsx:229-254`) → 버튼 아래 "출근은 HH:MM~HH:MM", 실패 시 대화에 문구 미리 채우기.
- `/gig/demo` 영상이 10/01 렌더본이라 '간편모드·잇기·닿기·관리자'가 나온다 → `capture_demo_screens.mjs worker-gig-live` → `render_demo_videos.mjs gig` 재제작, 나레이션 '초대 수락·출근하기·사장님'.
- `/intro`가 단기 사장님에게 병원 영상·병원 장점을 보여 준다(`intro/page.tsx:22-43, 60-82`) → 고른 유형에 따라 영상·장점 바꾸기, 첫 줄 단기 우선 여부는 대표 결정.
- QR 기본 주소 `/intro`는 '병원·의원'이 골라진 상태 → 팝업용 QR은 `/intro?role=admin&kind=gigworker`로 따로.
- 단기 요금 안내가 "이용 안내를 확인해 주세요"뿐(`intro/page.tsx:110`) → 가격 확정 후 한 줄.

- '잇기' 용어(근무자 잇기·잇기 대기) → '초대'로 통일할지 결정.
