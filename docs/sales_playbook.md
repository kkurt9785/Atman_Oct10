# 잇닿 영업 플레이북 v1 — 첫 고객 5곳까지

> 2026-08-13 작성. 삼촌 병원 피드백("사람이 안 나가서 쓸 이유가 없다")에서 도출한 원칙:
> **잇닿은 "인력이 자주 비는 곳"에서만 가치가 있다. 안 아픈 병원에 팔지 않는다.**
>
> 지금 단계 목표는 매출이 아니라 **레퍼런스 5곳**. 3개월 무료 + 세팅 대행으로 넣는다.

---

## 0. 순서 원칙 — 워커가 먼저다

원장에게 "인력 구해드립니다" 했는데 워커 풀이 비어 있으면 팔 게 없다.
**"수원에 대기 중인 간호조무사 30명 있습니다"** 가 되는 순간 영업이 아니라 공급 통보가 된다.

```
1주차: 워커 모으기(카페·당근) → 2주차: 공고 있는 상태로 병원 방문 → 3주차: 무료 파일럿 세팅
```

---

## 1. 첫 접촉 자산 — 뭘 건네줄 것인가

### 원칙: 원장은 QR을 찍어서 "가입"하지 않는다

QR의 목적은 가입 유도가 아니라 **"부담 0으로 90초 안에 이해시키고, 다시 연락할 명분을 남기는 것"**.
따라서 QR 목적지는 **로그인 화면이 아니라 공개 소개 페이지(영상 포함)** 여야 한다.

공개 소개와 공고 페이지가 준비되어 있다. 받는 사람이 중간 화면 없이 바로 볼 수 있도록 최종 페이지 주소를 사용한다.

- 사업장 영업 URL·QR: `https://itdot.co.kr/intro`
- 워커 모집 URL·QR: `https://itdot.co.kr/jobs`
- 카페·카톡 공고 공유: `https://itdot.co.kr/jobs/{공고ID}`

### 권장 조합 (우선순위)

| 상황 | 건네는 것 | 목적지 |
|---|---|---|
| **대면 방문** | 명함 크기 사업장용 QR 카드 1장 (원페이저는 두고 오기용) | `/intro` |
| **카톡 후속** | 90초 시연 영상 파일 직접 전송 + 링크 1개 | 영상 → 카톡 문의 |
| **워커 모집물** | 워커용 QR 카드·포스터 | `/jobs` |
| **카페·커뮤니티** | 실제 구인 공고 글 (홍보글 ❌) | `/jobs/{공고ID}` |

### QR 카드 문안 (명함 크기, 인쇄 1만원대)

```
─────────────────────────────
   간호사·간호조무사 대타,
   앱에서 바로 구합니다

   잇닿  itdot.co.kr

   [QR]        90초 영상으로 보기

   · 매칭 수수료 0원
   · 임금은 병원이 직접 지급
   · 직업정보제공사업 신고번호는 수리 후 실제 번호만 표기

   김기한  010-9045-5699
─────────────────────────────
```
> 뒷면은 비워두거나 "3개월 무료 파일럿 진행 중" 한 줄만.

## 2. 카톡 메시지 템플릿

### 원칙
- **5줄 이내.** 길면 안 읽는다.
- **링크 1개만.** 두 개 이상이면 둘 다 안 누른다.
- **요구를 최소화.** "가입해보세요" ❌ → "1분 영상만 봐주세요" ✅
- 첫 메시지에 가격 언급 ❌ (관심 생긴 뒤에)

### ① 방문 후 당일 (연락처 받았을 때) — 성공률 최상

```
원장님, 오늘 뵀던 잇닿 김기한입니다.
말씀하신 야간 대타 건, 저희 앱으로 어떻게 구해지는지
90초 영상으로 담아봤습니다. (영상 첨부)

지금 수원 지역 간호조무사 ○○명이 등록돼 있고,
3개월 무료로 세팅까지 대행해 드리고 있습니다.
편하실 때 3분만 통화 가능하실까요?
```

### ② 콜드 접촉 (지인 소개·전화 후)

```
안녕하세요, ○○원장님. ○○○님 소개로 연락드린
잇닿 김기한입니다.

병원에서 간호인력 갑자기 비었을 때
등록된 워커에게 바로 공고가 가는 앱을 만들었습니다.
(영상 첨부)

지금 수원·광주 지역 파일럿 병원을 찾고 있어서,
3개월 무료로 세팅까지 도와드리려 합니다.
관심 있으시면 편하실 때 회신 부탁드립니다.
```

### ③ 재접촉 (2주 후, 답 없을 때 1회만)

```
원장님, 지난번 인사드린 잇닿입니다.
그새 수원 지역 워커가 ○○명으로 늘어서
한 번 더 소식 전해드립니다.

혹시 이번 달 대타 구하실 일 생기면
공고 한 건만 무료로 올려드릴게요. 부담 없이 말씀 주세요.
```
> ※ 3회 이상 발송 금지. 정보통신망법상 영리목적 광고성 정보는 수신동의가 원칙 —
> **"공고 무료 대행 제안"처럼 요청받은 정보 형태로만** 보낸다. 대량 발송 절대 금지.

## 3. 방문 스크립트 (문 열고 3분)

### 방문 규칙
- **오후 2~4시** (진료 한가한 시간). 오전·점심·마감 직전 ❌
- 하루 5곳. 한 곳당 최대 10분.
- 복장: 셔츠·단정. 명함·QR카드·원페이저·폰(시연 준비 상태)

### 오프닝 — 팔지 말고 물어라

> "안녕하세요, 원장님 계실까요?
> 저는 병원 인력 관리 앱 만드는 잇닿 김기한입니다.
> **오늘 뭘 팔러 온 건 아니고요**, 요즘 병원들 대타 인력 어떻게 구하시는지
> **3분만 여쭤보려고** 왔습니다."

→ 통증이 있는 곳은 여기서 알아서 말을 시작한다. 없으면 빠르게 나온다. (그게 목적)

### 핵심 질문 3개 (이것만 알아내면 성공)

1. "간호사분 갑자기 못 나오시면 보통 어떻게 하세요?"
2. "직접 아는 분한테 연락 돌리시는 편이세요, 아니면 어디 올리세요?"
3. "그럴 때 제일 번거로운 게 뭐예요?"

### 통증이 나오면 → 폰 시연 (90초)

> "그거 저희가 이렇게 해결합니다."
> **화면 3개만 보여준다: ①공고 등록(30초) ②워커 지원 알림 ③출퇴근 GPS·QR 인증**
> "임금은 병원이 직접 지급하시고, 저희는 매칭 수수료 안 받습니다. 월 이용료만 받아요."

### 클로징 — 계약이 아니라 다음 약속

> "지금 수원에서 파일럿 병원 몇 곳 모시고 있는데,
> **3개월 무료에 세팅까지 제가 직접 해드립니다.**
> 이번 주에 공고 한 건만 시험 삼아 올려보시겠어요?"

### 거절 대응

| 거절 | 대응 |
|---|---|
| "우린 사람 안 나가요" | "다행이네요. 혹시 나중에 급하게 필요하실 때 쓰실 수 있게 명함만 두고 갈게요." **(빠르게 철수 — 좋은 정보를 얻은 것)** |
| "지금 바빠요" | "네, 명함이랑 자료만 두고 가겠습니다. 나중에 3분 통화만 부탁드려도 될까요?" → **연락처 확보가 목표** |
| "돈 드는 거죠?" | "3개월은 무료고요, 그 뒤에도 매칭 수수료는 0원입니다. 월 이용료 ○만원이 전부예요." |
| "직원 시켜서 구하면 돼요" | "그 시간이 아까우실 것 같아서요. 공고 올리고 지원자 확인까지 5분이면 끝납니다." |
| "우리는 아는 사람만 써요" | "그 분들 그대로 쓰시면서, 그 분들 근태·급여 정리만 저희로 하셔도 됩니다." **(인력풀 반복초대 기능으로 전환)** |
| "개인정보는 안전한가요?" | "직업정보제공사업 신고 완료했고, 급여 정보는 원장님만 보이도록 권한 분리돼 있습니다." |

## 4. 카페·커뮤니티 (워커 모으기)

### 원칙: 홍보글은 죽고, 구인 정보는 산다

카페는 "우리 앱 써주세요" 글을 삭제·강퇴한다. 대신 **실제 공고**는 환영받는다.
직업정보제공사업 신고 수리 여부와 실제 신고번호를 확인한 뒤 게시물의 사업자 고지를 확정한다.

### 대상
간호조무사 카페(간조사랑 등), 간호사 커뮤니티(널스토리·간호사연합), **지역 맘카페**(수원·광주),
당근마켓 알바, 약사 커뮤니티(대체약사 구인)

### 게시글 템플릿 — 공고 형태

```
[수원 권선구] 8/20(수) 야간 간호조무사 대타 구합니다

· 근무: 8/20(수) 22:00 ~ 익일 07:00 (9시간)
· 시급: 22,000원 (야간수당 포함)
· 업무: 병동 라운딩, 활력징후 체크
· 자격: 간호조무사 면허
· 임금은 병원에서 직접 지급합니다 (중개 수수료 없음)

지원은 아래에서 바로 가능합니다 → [링크]
문의 010-9045-5699
```

### 하지 말 것
- ❌ 같은 글 여러 카페 동시 도배 (IP 차단)
- ❌ "앱 다운로드 이벤트" 류 홍보 (즉시 삭제)
- ❌ 존재하지 않는 공고 올리기 (신뢰 즉사 + 법적 리스크)
- ✅ 가입 인사 → 며칠 활동 → 그 다음 공고 게시 (신규 계정 즉시 게시는 스팸 판정)

## 5. 예산 원칙 — 버스광고 하지 않는다

| 안 | 비용 | 판정 |
|---|---|---|
| 버스 광고 | 300~500만원 | ❌ **금지.** B2B 상품인데 B2C 매체. 타깃 도달률 1% 미만. 전환 경로 없음 |
| 방문 영업 | 교통비 | ✅ **1순위.** 통증 확인 + 레퍼런스 확보 |
| 카페·당근 | 0원 | ✅ **1순위.** 워커 공급 확보 |
| 공개 공고 SEO | 개발 공수 | ✅ **2순위.** "수원 간호조무사 대타" 검색 유입 |
| 당근 지역광고 | 일 1~3만원 | ⚠️ 첫 고객 확보 후. 반경 타게팅 가능 |
| 인스타 관심사 광고 | 일 1~3만원 | ⚠️ 워커 모집용으로만 |

> 지금 300만원은 광고비가 아니라 **런웨이(생존 자금)**. 첫 고객 10곳까지 버티는 데 쓴다.
> 레퍼런스 병원 1곳이 광고 1억보다 세다 — "○○요양병원도 쓰고 있습니다"가 다음 문을 연다.

## 6. 이번 주 실행 (체크리스트)

- [ ] 카페 3곳 가입 + 활동 (즉시 게시 ❌)
- [ ] 워커 등록 목표 20명 (카페·당근·지인)
- [ ] 타깃 리스트에서 **요양병원·검진센터·약국 20곳** 주소 확정 (→ `sales_target_hospitals.md` v2)
- [ ] QR 카드 100장 인쇄 (소개 페이지 완성 후)
- [ ] 방문 5곳 × 3일 = 15곳 (질문 3개만 받아오기)
- [ ] 방문 결과 기록: 통증 있음 / 없음 / 재방문 약속
