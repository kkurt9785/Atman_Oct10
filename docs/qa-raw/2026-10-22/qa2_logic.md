## 잘 된 점 (3개)
1. **전 구간 숫자 정합** — 공고 등록 → 근무자 알림·목록·지도 → 지원 → 관리자 지원자 → 수락 → 확정 알림·채팅방 → 근태 탭·채팅 목록·인건비까지 열한 군데 카운트가 한 번의 어긋남 없이 움직였고, 지원 즉시 '사업장 확인 중'·수락 즉시 '확정' 칩이 기본 화면에 보인다.
2. **10/14 P0 두 건이 제대로 닫힘** — 지급 대기가 해당 달로 열리고(`?month=`), 일할 전 월급은 합계에서 빠지며 행에 '합계 제외'가 적힌다. 지도 필터·오늘 확정 노출·시작 지난 확정 전이·근태 내역 일치도 모두 반영.
3. **예외 경로가 관리자에게 바로 닿음** — 출근 인증 실패·대타 요청·새 메시지가 수 초 안에 관리자 알림·홈 할 일·근태 '확인 필요'에 반영되고, 결원 요청은 기본 체크된 1명에게 1클릭으로 나간다. 자동 지표(typecheck·vitest 247·4xx 0·NaN 0)도 깨끗하다.
