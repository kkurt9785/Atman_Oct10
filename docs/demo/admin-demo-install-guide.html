잇닿 관리자 앱

시연 보기 · 설치 안내
잇닿은 어떤 앱인가요?

병원·약국과 간호사·약사·단기 근무자를 한곳에 모아, 근무 공고와 지원부터 출퇴근·급여 확인까지 하나의 앱에서 관리하는 인력 운영 서비스입니다.

직접 채용 방식 · 소개 수수료 0원

아래 시연은 1분이면 끝나요. 앱스토어 다운로드는 필요 없어요.
파란 글씨를 누르면 바로 열려요.

방법 1

설치 없이 바로 보기

링크를 누르면 로그인 없이 시연 화면이 바로 열려요.

병원 시연admin.itdot.co.kr/login?demo=hospital
약국 시연admin.itdot.co.kr/login?demo=pharmacy
요양병원 시연admin.itdot.co.kr/login?demo=care
긱워커 근태 시연admin.itdot.co.kr/login?demo=gigworker

· 카카오톡에서 눌러도 그대로 열려요.

방법 2

앱으로 설치해서 보기

홈 화면에 아이콘이 생겨 다음부터는 바로 열 수 있어요.

1
아래 버튼을 눌러요
카카오톡에서 누르면 브라우저가 자동으로 열려요.
관리자 앱 설치하기 →
2
안드로이드는 화면의 [관리자 앱 설치] 버튼
아이폰은 아래 공유 버튼 → [홈 화면에 추가]
3
홈 화면의 잇닿 관리자 아이콘을 열고
카카오로 시작해요.
방법 3

시연에서 이렇게 눌러보세요

화면 아래 탭 이름 그대로 적었어요. 순서대로 누르면 흐름이 보여요.

병원 · 약국 · 요양병원 시연

아래 탭 홈 · 모집 · 근태 · 직원 · 관리

홈

오늘 처리할 일에서 확인이 필요한 업무(대타 승인 · 지급 대기 등)를 먼저 봐요. 큰 버튼 근무자 모집은 날짜와 시간만 정하면 공고가 올라가요. 함께한 근무자 다시 요청, 외부 단기근로자 초대도 여기 있어요.

모집

올린 공고 목록이에요. 지원 현황에서 지원자를 보고 지원 수락을 누르면 근태·지급 흐름에 바로 연결돼요.
확정된 근무자가 못 오게 되면 맨 위에 대타 요청이 떠요. 함께 일해 본 워커가 맡겠다고 하면 승인 한 번으로 근무자가 바뀌어요. (병원 · 요양병원 시연)

근태

오늘 근태에서 출퇴근과 조퇴 확인 요청을 처리해요. 출퇴근 인증센터에서 GPS · 동적 QR · 사업장 네트워크 방식을 고를 수 있어요.

직원

기존 직원과 단기 인력을 한 화면에서 봐요. 휴가 관리에서 잔여 휴가 확인과 신청 승인을 해요.

관리

인력 공백 관리에서 직군·시간대별 필요 인원과 미충원·노쇼 대응을 봐요. 급여 지급에서 확정 근태 기준 예상 금액을 보고, 사업장이 직접 지급한 상태를 기록해요. 요금·청구도 여기예요.

긱워커 근태 시연 (팝업스토어)

아래 탭 운영 · 근무자 · 대화 · 관리

운영 (홈)

세 카드가 전부예요. 근태 기록(출퇴근·조퇴 확인) · 지급 관리(금액·계좌·지급일) · 현장 인증(GPS·동적 QR).

두 기기로 끝까지 보기 ★

홈에 있는 "워커 기기" QR을 다른 폰으로 찍으면 워커 시연 계정이 바로 열려요. 그 폰에서 초대 수락 → 닿기(출근)를 하면 관리자 화면에 바로 반영돼요. 다시 찍으면 처음 상태로 돌아가요.
워커 폰 링크: itdot.co.kr/gig/demo

대화

워크룸에서 근무자와 1:1로 이야기해요. 근무 끝나면 지급 관리에서 바로, 또는 날짜를 정해 지급을 기록해요.

주요 기능 한눈에

  • 공고 등록 · 지원자 확인 · 사업장이 직접 승인
  • 대타 요청 — 확정 근무자가 빠지면 함께 일해 본 워커가 맡고 사업장이 승인
  • GPS · 동적 QR · 사업장 네트워크 출퇴근 인증, 관리자 근태 보정
  • 연차 · 반차 · 반반차 · 시간차 신청과 승인
  • 월급 · 시급 · 일급 기준 세전 예상 급여, 직접 지급 상태 관리, 지급 검토 CSV
  • 약국: 약사 · 대체약사 · 전산/사무직 통합 등록, 검증된 약사 반복근무 요청
  • 임금 보관 · 자동 공제 · 소개 수수료 없음 — 사업장이 직접 채용하고 직접 지급해요
