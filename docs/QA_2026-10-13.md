## 남은 것

- **배포**: 관리자 앱을 먼저 배포한다(보안 건). 배포 후 시연 계정 직원 화면에서 면허 심사 섹션이 사라졌는지 확인한다.
- **감사 기록 확인**: 시연 관리자 계정으로 실제 근무자를 승인하거나 거절한 기록이 있는지 본다(아래 SQL).
- **서버 쪽 보강(제안)**: `get_nearby_open_shifts_secure`, `list_public_shifts`가 이미 시작한 오늘 공고를 돌려준다. 지금은 화면에서 거르지만, 지원 RPC에서도 막는 편이 안전하다.
- **사용자 결정이 필요한 것**
  - 하단 탭 '소식' → '알림'(화면 제목과 맞추기)
  - 근무 찾기 모드 안의 탭 '근무 찾기' → '공고'
- **시연 데이터(시드) 정리**
  - 이름에 '(데모)'·'데모워커'가 붙어 있다
  - '함께한 근무자'가 '누적 0시간'으로 나온다(출퇴근 기록 없음)
  - '기준 70명 중 등록 5명 → 65명 부족'
  - 공고 설명에 '시연용… 데모 워커' 문구가 있다
  - 출퇴근 기록이 서로 맞지 않는다
  - 8월 알림이 안 읽음 상태로 남아 있고, 예전 '새 시프트 공고' 알림 제목도 그대로다
- **영상**: 초대 근무 시연 영상에 '긱워커 간편모드'·'닿기'(폐기된 이름)가 나온다. 다시 찍어야 한다.

```sql
-- 시연 관리자 계정이 실제 근무자를 심사한 기록 (Supabase SQL 편집기에서 읽기)
select a.created_at, a.action, a.entity_id
from audit_logs a
where a.action like 'worker.verify.%'
  and a.actor_id in (select admin_user_id from facilities where is_demo);
```
