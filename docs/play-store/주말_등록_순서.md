## 1. Play Console 조직 계정 (D-U-N-S 있을 때, 30분)

1. https://play.google.com/console/signup → **조직** 선택
2. D-U-N-S, 법적 이름(케셰르), 주소, 전화, 웹사이트 `https://itdot.co.kr`, 공개 연락처 이메일 입력
3. 등록비 25달러 결제 → 이메일·전화 인증
4. 조직 확인은 며칠 걸릴 수 있어요. 확인 전에 앱 만들기·자료 입력은 해 둘 수 있어요.

> D-U-N-S 가 아직 없으면 2번(키·빌드)만 해 두고, 3번부터는 번호가 나온 뒤에 해요.

## 2. 업로드 키·빌드 (15분)

```bash
cd ~/atman
scripts/android/make-upload-key.sh     # 한 번만. 끝에 나오는 업로드 키 SHA-256 을 적어 둬요
scripts/android/build-aab.sh --apk     # dist/itdot-worker-1.0.0-1.aab (+ 폰 시험용 apk)
```
- `~/itdot-keys/itdot-upload.jks` 와 비밀번호를 **서로 다른 두 곳**에 백업해요(예: 비밀번호 관리자 + 외장 드라이브). 잃어버리면 Play 지원팀에 재설정을 요청해야 해요(며칠).

## 3. 앱 만들기 + 등록 정보 (1~2시간)

1. **앱 만들기**: 앱 이름 `잇닿 근무자 - 병원·약국 근무와 출퇴근`, 기본 언어 한국어, 앱, 무료
2. **앱 콘텐츠**(README 1~11절 순서 그대로): 개인정보처리방침 → 앱 액세스(로그인 없이 시연 입구, 문구 있음) → 광고 없음 → 콘텐츠 등급 → 타겟층 18세 이상 → 뉴스 아님 → 데이터 보안 → 정부·금융·건강 아님
3. **스토어 등록정보**(README 12절): 간단한 설명·자세한 설명 붙여 넣기, 그림 올리기
   - 아이콘 `assets/icon-512.png` · 그래픽 이미지 `assets/feature-graphic.png` · 휴대폰 스크린샷 `assets/phone-1.png`~`phone-6.png`
4. 카테고리 **비즈니스**, 연락처 이메일

## 4. 내부 테스트 → 주소창 없애기 (30분)

1. 테스트 및 출시 → **내부 테스트** → 새 버전 → `dist/itdot-worker-1.0.0-1.aab` 업로드(Play 앱 서명은 기본값) → 테스터에 내 Gmail → 출시
2. 앱 무결성 → Play 앱 서명 → **'앱 서명 키 인증서' SHA-256** 복사 (업로드 키 지문과 다른 값)
3. ```bash
   node scripts/android/assetlinks.mjs <앱 서명 키 SHA-256> <업로드 키 SHA-256>
   git add apps/worker-web/public/.well-known/assetlinks.json && git commit -m "Play 앱 assetlinks"
   cd apps/worker-web && vercel --prod --yes
   ```
4. 확인: `https://itdot.co.kr/.well-known/assetlinks.json` 이 열리고 → 폰에서 테스트 참여 링크로 설치 → 앱을 열었을 때 **위쪽 주소창이 없으면** 성공
5. 같은 폰에서 확인할 것: 카카오 로그인(로그인 중 카카오 화면에만 주소창이 잠깐 보이는 건 정상) · 알림 허용 → 알림 하나 받아 보기 · 출근하기 위치 허용

## 5. 프로덕션 출시 (10분 + 심사 대기)

- 프로덕션 → 국가 **대한민국** → 내부 테스트 버전을 승격 → 검토 제출
- 새 계정의 첫 심사는 보통 며칠~1주 걸려요.

## 6. 스토어 공개 뒤

- `apps/worker-web/lib/android-app.ts` 의 `live` 를 `true` 로 → worker-web 배포 → `itdot.co.kr/app` 의 안드로이드 안내가 'Play 스토어에서 받기'로 바뀌어요(아이폰은 그대로 홈 화면에 추가).
- 앱 내용을 바꿀 때는 웹만 배포하면 돼요. 앱 자체(이름·아이콘·색)를 바꿀 때만 `version.properties` 를 올려 다시 빌드·업로드해요.

## 알아 둘 것

- **알림 아이콘**: 지금은 상태 표시줄 알림 아이콘이 흰 사각형으로 보여요. 흰 글자만 있는 투명 PNG 를 사이트에 올리고 `twa-manifest.json` 의 `monochromeIconUrl` 로 다시 만들면 고쳐져요(출시를 막는 문제는 아니에요).
- **실기기에서 아직 안 본 것**: 카카오 로그인, 실제 푸시, 상태 표시줄 색. 4-5 단계에서 확인해요.
