# 직업정보제공사업 신고 — 방문 준비 가이드

> 근거: 직업안정법 제23조 (신고제 — 등록·자격 불필요)
> 판정: 국민신문고 회신 2026-07-23 (고용노동부 고용서비스정책과 044-202-7336) — `docs/legal_ruling_job_info_provider.md`

## ⚡ 온라인 제출 (정부24) — 방문 불필요

- **민원명**: "직업정보제공사업신고" — 정부24 검색 (민원코드 14900000009)
- **수수료 무료 · 처리기간 7일** · 처리기관 = 사업장 소재지 관할 지방고용노동청

### 절차
1. [정부24](https://www.gov.kr/mw/AA020InfoCappView.do?HighCtgCD=A05003&CappBizCD=14900000009) 접속 → 로그인 (공동인증서 또는 간편인증)
2. "직업정보제공사업신고" → **신청하기**
3. 신청서 작성 (별지 제27호서식 온라인 폼):
   - 상호: 사업자등록증 그대로 / 사업소 소재지 / 대표자 인적사항
   - **정보제공 방법: "컴퓨터통신(인터넷 웹사이트 및 모바일 앱)"**
   - 제공 정보 범위: "의료기관·약국의 구인정보 및 의료인력(간호사·간호조무사·약사 등)의 구직정보"
   - 사이트 주소: itdot.co.kr
4. 첨부: **사업자등록증 사본 1부** (그 외 타법 인허가 증빙은 해당 없음)
5. 접수 완료 → 담당 공무원 배정 (보완·확인 전화가 올 수 있음 — 아래 3번 예상 질문 답변 그대로)
6. 처리 완료 시 **신고확인증** 발급 (정부24에서 출력 또는 우편/방문 수령 선택)

### 팁
- 담당자 확인 전화가 오면: 아래 2번 설명문 그대로 + "고용노동부 국민신문고 회신(2026-07-23, 고용서비스정책과)으로 직업정보제공사업 해당 확인받았다"고 언급. 보완 요구 시 회신문 PDF 첨부 제출
- 신청서의 "제공 방법"을 간행물이 아닌 **컴퓨터통신**으로 정확히 체크 (법 제2조의2 제8호의 유형 구분)

## (방문 제출 시) 0. 가기 전에 (전화 1통)

**사업자등록증상 사업장 소재지 관할 지방고용노동청(지청)** 민원실에 전화해서 확인:
- [ ] 직업정보제공사업 신고 담당 부서·방문 시간
- [ ] 서식을 현장 작성하는지, 미리 작성해 가는지
- [ ] 추가 요구 서류 유무 (지청마다 안내가 조금씩 다름)

관할 찾기: 고용노동부 홈페이지 → 기관소개 → 소속기관 (또는 국번없이 1350)

## 1. 지참물 체크리스트

- [ ] **사업자등록증 사본**
- [ ] 대표자 신분증
- [ ] **국민신문고 회신 출력본** (`legal_ruling_job_info_provider.md` 인쇄 — "소개업 아니냐" 질문에 대한 방패)
- [ ] 도장 (간인용, 있으면)
- [ ] 아래 2번 "사업 내용 설명문" 출력본

## 2. 신고서 기재용 — 사업 내용 설명문 (그대로 쓰거나 읽어주기)

> 컴퓨터통신(웹·모바일 앱 "잇닿", itdot.co.kr)을 통해 의료기관·약국의 구인 공고를 게시하고, 구직자(간호사·간호조무사·약사 등)가 게시된 공고를 **직접 열람하여 스스로 지원**하는 방식의 직업정보 제공 서비스입니다. 채용 여부 판단과 근로계약 체결, 임금 지급은 전적으로 구인자(사업장)가 직접 수행하며, 플랫폼은 채용 과정에 개입하지 않습니다. 수익은 구인자에게 받는 **월 정액 소프트웨어 이용료**뿐이며, 채용 성사에 연동된 수수료는 일절 없습니다.

핵심 키워드 (회신 문구와 일치시킬 것): **불특정 다수 · 직접 열람 · 스스로 지원 · 개입 없음 · 정액 이용료**
