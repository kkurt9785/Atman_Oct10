# 잇닿 데모 영상 촬영 가이드 (각 80초)

두 영상 모두 첫 5초에 `/intro` 또는 QR 목적지를 보여주고, 화면 전환은 한 번의 클릭과 짧은 설명으로 구성한다. 한 영상에 모든 메뉴를 나열하지 않고 실제 영업에서 바로 쓰는 흐름만 보여준다.

## 관리자 영상 — `itdot_admin_demo_20260820.mp4`

| 시간 | 화면·행동 | 멘트 |
|---|---|---|
| 0–8초 | `/intro` → 관리자 데모 진입 | “잇닿은 병원·약국·요양병원의 모집부터 근태와 급여 검토까지 한 곳에서 처리합니다.” |
| 8–22초 | 관리자 홈의 오늘 처리할 일 | “홈에는 새 지원자, 출퇴근 확인, 지급 대기처럼 오늘 바로 처리할 일만 먼저 나옵니다.” |
| 22–36초 | 인력 모집 → 공고 → 지원 현황 | “날짜와 시간만 정해 공고를 만들고, 지원자가 오면 프로필과 자격 확인 후 수락합니다.” |
| 36–48초 | 채팅 목록 → 새 메시지 배지 → 채팅방 | “워커가 보낸 새 메시지는 목록에서 바로 표시되고, 확정된 근무 대화가 자동으로 열립니다.” |
| 48–62초 | 근무 관리 → 인증 실패·조기퇴근 확인 | “GPS가 실패했거나 조기퇴근 승인이 필요한 건은 홈 숫자와 근무 관리에서 바로 확인합니다.” |
| 62–74초 | 월 근태 → 급여 검토 | “정상·지각·조퇴·휴가·결근을 월 단위로 모아 급여 검토 자료로 이어집니다.” |
| 74–80초 | 알림 받은함 → 마무리 | “푸시를 놓쳐도 알림 받은함에서 다시 확인할 수 있습니다.” |

## 워커 영상 — `itdot_worker_demo_20260820.mp4`

| 시간 | 화면·행동 | 멘트 |
|---|---|---|
| 0–8초 | `/intro` → 워커 시작하기 | “잇닿은 내 지역의 병원·약국·요양병원 근무를 찾고, 지원부터 입금 확인까지 연결합니다.” |
| 8–20초 | 프로필·지역 설정 | “처음에는 이름과 직종, 활동 지역만 등록합니다. 약사·약국 사무직은 필요한 서류 안내를 따릅니다.” |
| 20–34초 | 근무 찾기 → 공고 카드 → 지원 | “조건에 맞는 공고를 보고 한 번 눌러 지원합니다. 지원 상태는 홈의 다음 행동 카드에서 바로 확인합니다.” |
| 34–47초 | 지원 현황 → 채팅 | “채용이 확정되면 사업장과 필요한 내용만 채팅하고, 새 알림은 앱 받은함에서도 확인합니다.” |
| 47–62초 | 오늘 확정 근무 → 출근하기 | “사업장에 도착하면 출근하기를 누릅니다. GPS를 우선 확인하고, 실내에서 불안정하면 60초 동적 QR로 보완합니다.” |
| 62–72초 | 퇴근하기 → 근태·급여 | “퇴근 후 근무시간과 인증 방식이 기록되고, 사업장 지급 상태는 급여 화면에서 확인합니다.” |
| 72–80초 | 알림·내 정보 화면 | “필요한 안내는 알림에 남아 다음 근무까지 놓치지 않습니다.” |

## 촬영 체크

- 계정: 관리자 `sales-demo-1`, 워커 `worker-demo-1` (W여성병원) 또는 `worker-demo-2` (온누리약국)
- 촬영 전 `python3 scripts/server_qa_demo1.py` 결과가 `total=30 pass=30 fail=0`인지 확인
- 관리자 영상은 홈 → 모집 → 채팅 → 근무 관리 → 월 근태 → 알림 순서
- 워커 영상은 `/intro` → 프로필 → 근무 찾기 → 지원 현황 → 출퇴근 → 급여 → 알림 순서
- 화면 체류는 2초 이내, 실제 클릭은 버튼 중심으로 촬영하고 개인정보·정확한 좌표는 노출하지 않는다.
